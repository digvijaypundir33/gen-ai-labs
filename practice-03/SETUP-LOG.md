# Practice 03 — Build Log & Cleanup Checklist

Everything I actually create on AWS for [Practice 03](./README.md),
in the order I create it, with what it costs and how to delete it again. Same purpose as the
Practice 01/02 logs: the Cleanup column is meant to be run top to bottom when I'm done, so nothing
gets left behind quietly billing.

Region: **us-east-1** throughout. This project deliberately **reuses** practice-02's existing
IAM user/role/API Gateways rather than standing up new foundational infrastructure — see the
main write-up's Stage 1 for the live audit that confirmed everything below was still active
before building on top of it.

**Status: in progress.** Rows get added as resources get created.
