# Setup Log — Practice 04

Everything I actually created on AWS for this practice, in the order I created it, with what it
costs and how to delete it again. **Region: us-east-1** throughout.

This project deliberately reuses practice-02/03's foundational infrastructure — the shared
IAM role (`rag-assistant-lambda-role`), the CLI user/profile (`rag-assistant-project-user` /
`rag-assistant`), both API Gateways (`rag-assistant-api` REST, `rag-assistant-ws-ap` WebSocket),
the S3 bucket (`rag-assistant-docs-dig-003`), the Step Functions role
(`rag-assistant-stepfunctions-role`), the Knowledge Base (`rag-assistant-kb-2`), and the
`ModelCircuitBreaker` DynamoDB table — rather than provisioning anything foundational from
scratch. Stage 1 was a live audit confirming all of that was still active before touching
anything. Only genuinely new resources are listed below.

**Status:** Stages 1-16 built and verified live, everything still running.
